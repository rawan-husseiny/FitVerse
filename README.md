# 👗 FitVerse — AI Outfit Recommendation Platform

> 🚧 **Work in Progress — This project is currently under development.**

FitVerse is a smart outfit recommendation platform designed to help users choose suitable outfits based on their personal style, occasion, weather, and preferences.

## ✨ Features

* 👤 User Registration & Login
* 🎨 Personal Style Profile
* 👗 Personalized Outfit Recommendations
* 🌤️ Weather-Based Outfit Suggestions
* 🎉 Occasion-Based Styling
* 🎨 Favorite Color Selection
* 📱 Responsive User Interface
* 🗄️ MySQL Database
* 🔐 PHP Backend

## 🛠️ Technologies Used

## 📌 Project Idea

Choosing an outfit can sometimes be difficult, especially when considering the weather, occasion, colors, and personal style.

FitVerse aims to simplify this process by providing personalized outfit suggestions based on the user's preferences and profile.

## 🚀 How to Run the Project

1. Install **XAMPP**.
2. Start **Apache** and **MySQL**.
3. Copy the project folder into:

```text
htdocs
```

4. Open **phpMyAdmin**.
5. Create a database for FitVerse.
6. Import the provided `.sql` file.
7. Make sure the database connection settings in the PHP files are correct.
8. Open the project through:

```text
http://localhost/FitVerse
```
